PROJECT SUMMARY
───────────────────────────────────────────────────────────────────

A full-stack Gym Management System built with:

  Backend:   ASP.NET Core 8 Web API
             Entity Framework Core (Code-First)
             ASP.NET Identity + JWT Bearer tokens
             Microsoft SQL Server

  Frontend:  React
             React-Bootstrap
             Axios
             React Router

  Roles:     Administrator, Personal Trainer, Gym Member
